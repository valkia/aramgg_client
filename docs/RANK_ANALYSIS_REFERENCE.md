# Rank Analysis 功能适配

参考项目：[wnzzer/rank-analysis](https://github.com/wnzzer/rank-analysis)，审阅版本 `3878348ed516252083d1fc3fde606affe0e2ce6c`（2026-10-28）。

本次将适合海克斯大乱斗战绩的交互适配到现有 Electron / Vue / i18n 结构：

| 功能 | 上游参考 | 本项目适配 |
| --- | --- | --- |
| 表现总览 | `components/record/RecentStatsTable.vue`、`UserRecord.vue` | 本页胜率、综合 KDA、场均 K/D/A、按时间排列的胜负走势和连续胜负标签；明确本页样本范围，排除重开 |
| 筛选工具栏 | `components/record/MatchHistory.vue` | 复用现有分页数据，按英雄和胜负组合筛选；明确只筛选当前页，成功加载页面后重置；失败保留原页与筛选，空结果仍可翻页；首次加载显示骨架 |
| 对局详情 | `components/record/MatchDetailModal.vue`、`RecordCard.vue`、`composables/useMatchDetailPlayers.ts` | 按需展开双方玩家、KDA、伤害及队内占比、参团率、承伤、经济、补兵、装备、海克斯和多杀标记；当前玩家高亮，不接入选禁、交换或其他 LCU 写入 |
| 玩家备注 | `components/common/PlayerNoteBadge.vue`、`pinia/playerNotes.ts` | 对局详情可添加四档颜色标签与文字备注；独立列表支持搜索、筛选、编辑和删除；本机按区服与玩家标识关联，同名玩家不合并 |
| 备注备份 | `views/settings/DataSync.vue` | 系统对话框选择 JSON 文件；导出仅包含备注，导入显示数量与前 10 条预览，确认后仅补充本机缺少的备注；已有内容保留本机版本 |
| 再次遇见 | `components/gaming/MettingPlayersCard.vue` | 按玩家与区服聚合本页重复相遇，显示同队／对手次数、我的胜负与重开、该玩家逐局英雄及 K/D/A；复用备注入口，点击可清除筛选并展开对应对局详情 |

保留现有深色金色主题，用本项目设计 token 和组件实现；不引入 Tauri、Naive UI 或新的服务依赖。AI 复盘需要模型服务与密钥，云同步需要后端，自动选禁不符合本项目 ARAM 推荐只读约定，均不在此迁移范围。

## 数据与边界

- 继续查询当前登录账号的海克斯大乱斗（队列 2400），没有新增全模式、其他玩家搜索或历史全量扫描。
- 详情复用当前 SGP SUMMARY 响应，保留 8 个额外标量字段，不增加逐局网络请求；原有战绩存储与上传 schema 不变。主进程生成 `区服:SHA256(PUUID)` 备注 key，原始 PUUID 不传给详情 UI；缺少稳定标识的玩家不提供备注入口。
- 缺失或非法数值保留为 `null`，显示为 `—`。队伍不足 5 人、伤害字段不全、分母为 0 时不生成误导性的百分比或队内最高伤害标记。此处没有模拟官方 MVP 评分。
- 玩家备注经受信任 IPC 读写 `app-paths.ts` 管理的配置目录内 `player-notes.json`；严格限制为 1000 条、单条 500 字符，串行原子写入，失败保留磁盘原值与编辑草稿，损坏文件不自动覆盖；不上传备注。
- 备注备份不包含设置、密钥或登录信息；4 MB 有界读取、版本与字段校验，导入预览绑定窗口并于 10 分钟后失效。确认操作使用已校验快照，串行写入时重新核对本机备注与容量，保留预览后发生的本机修改；取消选择不写文件。
- 好友/宿敌与开黑推断仍未接入。
- 相遇只统计当前已加载页，不新增请求或全历史扫描；忽略缺失标识、无法确认当前队伍或身份冲突的记录，明确显示可识别场数；同名不合并，重复对局与重复玩家条目不重复计数。
